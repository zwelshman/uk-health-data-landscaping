## 5. Gaps & Recommendations

- **Phenotype Library API outage**: All codelist retrieval failed (SSL errors). **Recommendation**: request BHF DSC **Computable phenotypes and codelists** service to supply validated MI/CKD/diabetes definitions and run bespoke codelist review for the candidate sets in `codelists.json`.
- **Population size data**: Gateway API does not expose structured `population_size`; 8 of 12 mapped datasets have unknown population. **Recommendation**: BHF DSC **Data discovery and project feasibility** (Population Data Dashboard) to confirm coverage before study design.
- **PIONEER AF dataset** (>24k admissions) is below the 60k threshold — flagged `⚠️ BELOW_THRESHOLD`; suitable for pilot analyses only.
- **GPDPR dataset** carries a COVID-only use restriction — flagged for access-route review.
- **dm+d / OPCS-4 codelists**: medication and procedure codelists are placeholders; require NHS dm+d browser retrieval.
- **CVD-COVID-UK programme context**: the BHF DSC reference notes the NHS England SDE data-sharing agreement ends January 2027 and no new projects are being accepted — projects targeting that route need alternative access plans.
